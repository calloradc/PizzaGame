# Pizza Patrol 2.0

Казуальная Tower Defense для телефона, планшета и ПК. 10 башен со специализациями, 15 разновидностей врагов (включая 4 боссов), 7 способностей, 3 карты и 4 режима. Интерфейс на React, игровая сцена на SVG. Для работы не требуется серверная часть.

## Что добавлено

- Чеснок снимает броню; огнемёт Чили наносит дополнительный урон замедленным целям; Трюфель пробивает группу вдоль дороги. У каждой башни две специализации и пять уровней.
- Лук-панцирь сбрасывает броню при половине здоровья и ускоряется; Попкорн-прыгун ослабляет замедление во время прыжков; Мятный чародей ускоряет союзников. Приоритет «Медики» выбирает обе разновидности поддержки.
- Импульс снимает щиты и оглушает врагов. Поставка добавляет ресурсы во время боя.
- Кампания: 18 волн в уютной сложности, 24 в остальных. Блиц: 12 быстрых волн и 470 стартовых ресурсов. Выживание: бесконечные волны. Заказ дня: 12 волн, фиксированная карта по дате UTC, классическая сложность и дополнительная награда за первую победу за день.
- Магазин открывает башни и способности навсегда. Новому игроку доступны Пепперони, Моцарелла, Соус и Лёд; стартовый кошелёк — 150. Покупка рецепта и строительство оплачиваются из разных балансов, оба отображаются иконкой. Волны, победы и задания пополняют постоянный кошелёк.
- Пять заданий с однократными наградами; рекорды сохраняются для каждого режима.
- Главное меню с выбором карты, сложности и режима. В бою постоянно видны показатели, две или три открытые способности и основные действия; остальные возможности открываются отдельными кнопками.
- Ползунки громкости и качества эффектов, вибрация, автоматические волны, русский и английский язык. Настройки сохраняются.

## Управление

Короткое касание плюса открывает строительство; касание башни — улучшения, специализации, приоритет и продажу. Поле двигается одним пальцем или левой кнопкой мыши; масштаб меняется щипком или колесом. Зум ограничен **0,9–1,8×**, перемещение ограничено границами поля. Интерфейс остаётся неподвижным.

Удержание дольше 600 мс и перетаскивание не активируют площадки. Правая кнопка и контекстное меню блокируются внутри игры. Повторные быстрые клики и повтор клавиш защищены от случайных действий. На ПК пробел переключает паузу, Escape отменяет прицеливание и закрывает панели. Диалоги поддерживают клавиатурную навигацию.

Интерфейс использует пропорциональные размеры с ограничениями для маленьких экранов, safe area и отдельную компоновку для горизонтальной ориентации. Меню и длинные списки прокручиваются, поле и HUD не прокручиваются вместе с ними.

## Реклама

**Реклама имитируется**, рекламные SDK и сетевые рекламные запросы отсутствуют. Просмотр длится 6 секунд. Кнопка получения награды активируется после таймера; закрытие окна ничего не начисляет. При скрытой вкладке таймер останавливается. Бой во время просмотра приостановлен.

Доступные награды:

- Магазин: +80 в постоянный кошелёк, повторный просмотр через 30 секунд. Ограничение сохраняется после перезагрузки.
- Между волнами: +100 ресурсов, один раз для каждой волны.
- После поражения: восстановить 8 жизней и повторить волну, один раз за забег.
- После завершения: удвоить заработанную за забег постоянную награду, один раз. Идентификаторы получивших бонус забегов сохраняются.

Для настоящей монетизации точку входа `watchAd` в `src/game/engine.js` нужно связать с подтверждённым завершением просмотра в SDK выбранной площадки. Текущая сборка честно показывает «Демо-реклама».

## Производительность

Атласы в публикации используют WebP; PNG-оригиналы остаются в исходниках. Восемь основных изображений занимают около 2 МБ вместо 12 МБ. Перед запуском 67 кадров выделяются в независимые текстуры не более 256 пикселей по длинной стороне.

Фон и карта движутся одним CSS transform: камера не изменяет SVG pattern и не обновляет React при перетаскивании. Пространственный индекс ограничивает поиск целей, лечение и эффекты ближайшими врагами. Декоративные эффекты имеют бюджет; при больших группах уменьшаются частицы, фильтры и походка. Тяжёлый бой обновляется с целевой частотой 30 кадров/с, камера — через отдельный requestAnimationFrame. Интерфейс боя обновляется четыре раза в секунду реального времени, независимо от выбранной скорости.

Без боя, эффектов и таймеров игровой цикл останавливается. Пауза и диалоги останавливают бой. Сырные лужи и другие механические эффекты продолжают работать при отключённой графике.

## Сохранения

Ключи localStorage `pizzaSaveV2`, `pizzaMeta`, `pizzaPrefs` сохранены. Старые сохранения читаются при публикации на прежнем домене. Игроки с прежним прогрессом сохраняют доступ к старым рецептам; башни из сохранения автоматически открываются. Прогресс магазина, задания, рекламные ограничения и настройки сохраняются независимо от забега.

Контрольная точка записывается перед волной и между волнами. После победы отдельно сохраняется экран результата: перезагрузка не повторяет выплату за победу. Во время незавершённой волны перезагрузка возвращает к её началу. Настройки и прогресс принадлежат текущему браузеру; синхронизации между устройствами нет.

## Разработка и проверки

Нужен Node.js 22.12+; в окружении используется Node.js 24.

```sh
npm ci
npm run dev
npm test
npm run test:browser
npm run build
```

Браузерные тесты используют production-сборку. Проверяются бой, боссы, новые механики, покупки и ограничения наград, старые сохранения, пауза, язык и ползунки, ПКМ и удержание, настоящие touch-жесты Chromium, границы камеры, шесть размеров экрана от 320×568 до 1440×900 и размещение в подпапке.

Нужны Python 3 и Chromium. При наличии `/usr/bin/chromium` он используется автоматически. Другой браузер можно выбрать через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` или установить:

```sh
npx playwright install chromium
```

## Публикация

```sh
npm run build
npm run preview
```

На хостинг загружается **содержимое `dist/`**: HTML, скомпилированные JS/CSS, WebP-ресурсы, шрифты и лицензия шрифта. Исходники, тесты, зависимости, PNG-оригиналы и исходный архив в сборку не включаются. Проверка сборки запрещает source maps, исходные файлы и архивы в каталоге публикации. Пути относительные, игра работает в подпапке сайта.

`.openai/hosting.json` указывает на `dist`. Для хостинга со сборкой из Git: команда `npm ci && npm run build`, каталог публикации `dist`.

В `.github/workflows/pages.yml` настроены проверка, сборка и публикация только `dist` при push в `main`. Для первой публикации владелец включает **Settings → Pages → Build and deployment → Source → GitHub Actions**. Если окружение `github-pages` требует подтверждения, публикация ожидает этого подтверждения. Обычный адрес репозитория — `https://calloradc.github.io/PizzaGame/`; он доступен после успешной публикации, если не настроен другой домен.

## Структура

- `src/App.jsx`, `src/components.jsx` — главное меню, магазин, настройки, HUD и диалоги.
- `src/GameScene.jsx`, `src/game/camera.js` — сцена, камера и жесты.
- `src/game/engine.js` — бой, режимы, реклама, сохранения.
- `src/game/config.js` — баланс, враги, карты, способности, специализации.
- `src/game/progression.js` — покупки, миграция прогресса, задания.
- `src/game/targeting.js` — пространственный индекс и приоритеты.
- `src/game/i18n.js` — перевод интерфейса и игровых сообщений.
- `src/game/art.js`, `src/assets/` — оригиналы и оптимизированные ресурсы.
- `src/styles/release.css` — актуальное оформление и адаптация.
- `scripts/`, `tests/` — проверки и браузерные сценарии.

`PizzaGame-source.zip` — архив предыдущей версии, оставленный для справки; он не используется новой игрой и не включается в публикацию.
