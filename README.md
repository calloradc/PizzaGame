# Pizza Patrol

Казуальная Tower Defense для телефона: 7 типов башен, 3 карты, способности, улучшения и сгенерированные растровые ассеты.

## Запуск

Нужны Python 3 для локального сервера и Node.js для проверок. Зависимостей npm нет.

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Игра использует ES-модули и загрузку ассетов, поэтому запуск через сервер обязателен.

## Проверки

```sh
node scripts/validate.mjs
node scripts/test-art.mjs
node scripts/test-isolation.mjs
```

## Структура

- `dist/index.html` — интерфейс.
- `dist/js/` — логика игры, баланс, анимации, звук и выделение спрайтов из атласов.
- `dist/css/` — оформление и мобильная компоновка.
- `dist/assets/` — PNG-атласы, текстура поля, SVG-сцена и локальные шрифты.
- `scripts/` — проверки ресурсов и обрезки спрайтов.

Сохранения хранятся в localStorage браузера игрока. Серверная часть не требуется. Для статического хостинга публикуйте содержимое `dist/`.
