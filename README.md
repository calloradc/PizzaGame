# Pizza Patrol

Казуальная Tower Defense для телефона на React: 7 типов башен, 3 карты, 4 разных босса, способности, улучшения и растровая графика. Интерфейс и меню рисует React, игровой движок отдельно обновляет SVG-сцену.

## Управление на телефоне

Квадратная карта находится в сцене на весь экран. Двигайте поле одним пальцем, приближайте и отдаляйте двумя. Короткое касание площадки открывает строительство; перемещение поля не выбирает площадки и не применяет способности. На компьютере работают перетаскивание мышью и колесо. Масштаб ограничен диапазоном 0,6–2,4×.

Показатели, способности и кнопки плавают поверх сцены и остаются на месте при движении камеры. Дополнительное меню открывается кнопкой с пиццей слева сверху; в нём есть справка, награды и полноэкранный режим. Интерфейс учитывает вырезы экрана и поворот телефона.

Фон — качественная текстура травы `grass-tile.png`, повторяемая зеркально без видимых обрывов. Кусты, деревья, скамейки, камни, цветы и заборы выделены из отдельного `decor-atlas.png` и расставляются с отступами от дороги, площадок и пиццерии. Декор и трава движутся вместе с камерой. Игровые координаты и формат сохранений сохраняют совместимость.

## Бой

Каждая шестая волна приносит нового босса: Король корки призывает отряд, Споровый барон восстанавливает здоровье и защищает соседей щитами, Шеф Чили предупреждает об огненном залпе и временно оглушает ближайшие башни, Генерал Томат восстанавливает щит и ускоряет отряд. Чили и Генерал ускоряются во второй фазе. В бесконечном режиме порядок боссов повторяется.

Босс появляется в середине группы с поддержкой. Волны стали плотнее, здоровье растёт быстрее, с девятой волны встречаются усиленные враги. Уютный режим сохраняет меньшие группы и более короткие оглушения; классика и острый режим требуют сочетать башни и способности.

Башни зеркалятся к цели; уровни обозначены отдельными звёздами. Урон ядом и горением не перезапускает вспышку попадания каждый кадр. У теста есть анимация разделения на две половинки с появлением крошек; призыв и способности боссов имеют подготовку и эффекты появления.

Движок выбирает цели за один проход, кеширует характеристики башен и неизменившиеся SVG-атрибуты, ограничивает декоративные частицы. Атласы превращаются в 58 независимых текстур до начала игры: экземпляры спрайтов не создают собственные маски. Интерфейс обновляется четыре раза в секунду во время боя; камера не перерисовывает React. При отсутствии боя, эффектов, таймеров способностей и автоматической волны цикл кадров останавливается, а в паузе не обновляет игровую сцену. Механические эффекты, например замедляющие лужи, сохраняются при заполнении бюджета частиц.

## Разработка

Нужен Node.js 22.12+ (в облачной среде используется Node.js 24).

```sh
npm ci
npm run dev
```

Vite запускает сервер разработки и обновляет игру при изменении исходников. Адрес и порт отображаются в терминале. Сервер разработки используйте для работы над игрой.

## Сборка и публикация

```sh
npm run build
```

Публикуйте **только содержимое `dist/`**. Сборка содержит HTML, минифицированные JS/CSS с хешами в именах и игровые ресурсы. Файлы из `src/`, тесты, npm-пакеты и архив `PizzaGame-source.zip` в неё не копируются. Карты исходников отключены; отдельная проверка сборки запрещает исходные архивы, исходники JSX/TS и source maps в `dist/`.

Для проверки готовой сборки:

```sh
npm run preview
```

Настройка `.openai/hosting.json` указывает на `dist/`. На хостинге, собирающем проект из Git, задайте `npm ci && npm run build` и каталог публикации `dist`. Папка `dist` генерируется заново и исключена из Git. В ней также остаётся лицензия локального шрифта. Относительные пути позволяют размещать игру в подпапке сайта, например `/pizza/`.

React и минификация не скрывают выполняемый браузером JavaScript: посетитель может скачать и изучить собранный код. Исходники проекта остаются в репозитории; если нужно ограничить доступ к ним, репозиторий должен быть приватным. Секреты нельзя помещать в клиентский код.

## GitHub Pages

В репозитории настроен `.github/workflows/pages.yml`. При отправке изменений в `main` GitHub Actions устанавливает зависимости из lockfile, проверяет ресурсы и игровые сценарии в Chromium, собирает игру и публикует **только `dist/`**. Для публикации используется стандартный `GITHUB_TOKEN` самого workflow; отдельный токен или секрет для сборки не нужен.

Первичная настройка владельцем репозитория: **Settings → Pages → Build and deployment → Source → GitHub Actions**. Включение Pages — отдельная настройка репозитория: workflow не запрашивает административный токен и не включает её автоматически. Если репозиторий приватный, доступность Pages зависит от тарифа GitHub.

После включения Pages запустите **Actions → Build and deploy Pizza Patrol → Run workflow → main** или отправьте новое изменение в `main`. После успешного шага публикации GitHub показывает ссылку в deployment `github-pages`. Для `calloradc/PizzaGame` стандартный адрес — `https://calloradc.github.io/PizzaGame/`, если не настроен отдельный домен. До успешной публикации этот адрес может возвращать 404.

Если настроено обязательное подтверждение environment `github-pages`, deployment будет ждать одобрения владельца репозитория. Обновление игры в дальнейшем выполняется автоматически при push в `main`.

## Проверки

```sh
npm test
npm run build
npm run test:browser
```

`npm test` проверяет ресурсы, ссылки, синтаксис движка, 57 определений спрайтов, выделение 58 кадров атласов, выбор целей, порядок боссов, ограничения волн и сохранение механических эффектов. `npm run build` собирает React и проверяет состав публикации. Браузерные тесты используют готовую сборку: строительство, улучшения и продажу башен, способности, бой и паузу, меню, старые сохранения, бонусы, победу, поражение, бесконечный режим, восстановление после ошибки загрузки и размещение в подпапке. Дополнительные сценарии проверяют яд, зеркалирование башен, разделение теста, все четыре способности боссов, остановку кадров в паузе и при бездействии, таймеры способностей и геометрию всех карт. Отдельные сценарии отправляют настоящие события касания Chromium: перемещение, зум двумя пальцами, отмена жеста, поворот экрана и точное применение способности после движения камеры.

Для браузерных тестов нужны Python 3 и Chromium. Если установлен `/usr/bin/chromium`, он используется автоматически. Можно указать другой исполняемый файл через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` или установить браузер Playwright:

```sh
npx playwright install chromium
```

## Структура

- `src/App.jsx`, `src/components.jsx` — React-интерфейс, показатели, строительство и меню.
- `src/GameScene.jsx`, `src/game/camera.js` — квадратная сцена, повторяемая трава и управление камерой.
- `src/game/engine.js` — экземпляр игрового движка, SVG-анимация, бой и сохранения; освобождает таймеры, наблюдатели и обработчики при завершении.
- `src/game/` — баланс, звук, эффекты и работа с атласами.
- `src/styles/`, `src/assets/` — стили и исходные ресурсы.
- `public/assets/font-notice.txt` — лицензия шрифта, копируемая в сборку.
- `scripts/`, `tests/` — проверки ресурсов, публикации и браузерных сценариев.
- `dist/` — результат production-сборки.

Сохранения и настройки хранятся в localStorage. Ключи `pizzaSaveV2`, `pizzaMeta` и `pizzaPrefs` сохранены: прогресс старой версии читается при публикации на том же домене. Серверная часть для игры не требуется.

`PizzaGame-source.zip` — архив исходной версии от 4 октября 2026 года, оставленный для справки. Он не используется при разработке новой версии и не включается в публикацию.
